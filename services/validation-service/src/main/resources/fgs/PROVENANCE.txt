FGS Paketstruktur schema set, as published by Riksarkivet.

Bundled rather than fetched at validation time. A conformance check that
depends on a remote host is not reproducible: it becomes a different check when
the host is down, and a silently different one if the file changes. These are
the bytes the package was validated against, and their digests are asserted by
the build.

These are the profile's published schemas. They are NOT the receiving archive's
schema set: an archive chooses its FGS version and may mandate local profile
extensions. Validating against these proves the package follows the published
profile, which is a smaller claim, and the difference is tracked as an external
blocker against requirements 2064 and 2065.
