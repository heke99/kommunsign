# Stable API and worker error codes

Client responses contain stable codes and generic messages. Provider payloads, stack traces, personal numbers and secrets are never returned.

## Identity and signer

`PERSONAL_NUMBER_REQUIRED`, `PERSONAL_NUMBER_INVALID`, `PERSONAL_NUMBER_EXCEPTION_NOT_ALLOWED`, `PERSONAL_NUMBER_EXCEPTION_REASON_REQUIRED`, `PERSONAL_NUMBER_MISMATCH`, `SIGNING_ORDER_BLOCKED`, `DOCUMENT_REVIEW_REQUIRED`.

## Document

`DOCUMENT_NOT_READY`, `DOCUMENT_INFECTED`, `DOCUMENT_PDF_POLICY_REJECTED`, `DOCUMENT_PAGE_LIMIT_EXCEEDED`, `DOCUMENT_PDFA_CONVERSION_FAILED`, `DOCUMENT_PDFA_VALIDATION_FAILED`, `DOCUMENT_HASH_MISMATCH`, `UPLOAD_GRANT_ALREADY_USED`.

## Invitation and BankID

`INVITATION_INVALID`, `INVITATION_EXPIRED`, `INVITATION_REVOKED`, `TIC_NOT_CONFIGURED`, `TIC_RATE_LIMITED`, `TIC_SESSION_EXPIRED`, `TIC_WEBHOOK_SIGNATURE_INVALID`, `TIC_WEBHOOK_REPLAYED`, `TIC_EVIDENCE_INVALID`, `TIC_SIGNATURE_INVALID`, `TIC_OCSP_MISSING`.

## Evidence and email

`EVIDENCE_PACKAGE_NOT_READY`, `EVIDENCE_ZIP_INVALID`, `EMAIL_PROVIDER_NOT_CONFIGURED`, `EMAIL_TEMPORARY_FAILURE`, `EMAIL_PERMANENT_FAILURE`, `EMAIL_WEBHOOK_SIGNATURE_INVALID`, `EMAIL_WEBHOOK_REPLAYED`, `EMAIL_COMPLIANCE_APPROVAL_REQUIRED`.

## Platform

`IDEMPOTENCY_KEY_REQUIRED`, `IDEMPOTENCY_CONFLICT`, `RESOURCE_VERSION_CONFLICT`, `TENANT_NOT_READY_FOR_ACTIVATION`, `NOT_FOUND`, `FORBIDDEN`, `VALIDATION_ERROR`.

Unknown internal failures are mapped to a generic internal error and a request ID. Operations uses the request ID and redacted structured logs for investigation.
